# Assets

Everything here is generated by code in `scripts/` or bundled with Blender under an open license.

- `screens/`: in-world screen graphics (laptop, monitor, notebook handwriting, stadium display,
  crowd announcement atlas, desk clock digits, whisper caption). Generated by
  `generate_screens.py`, `generate_clock.py` and `generate_captions.py`. See `screens/README.md`.
- `fonts/`: Inter (SIL OFL 1.1) and DejaVu Sans Mono (Bitstream Vera license), copied from
  Blender 5.2's bundled datafiles, with their license texts.

No third-party models, textures or HDRIs are used. See `docs/asset_disclosures.md`.
